# Python医院信息管理系统简介

## 核心功能
- 医生管理
- 患者管理
- 病房管理
- 科室管理
- 药品管理
- 生成药品单据

## 适用场景
- 医院内部信息管理
- 医疗机构内部运营
- 医疗数据统计与分析

## 技术特点
- 采用Django框架进行开发，确保系统稳定性和扩展性
- 使用MySQL数据库存储数据，保证数据安全和高效查询
- 前端界面采用HTML、CSS和JavaScript，提供良好的用户体验
